# Continuous experience roadmap

## Current pass — a visible replacement, not another effect

One identity-first journey precedes Work:

1. **Question:** STRANGE QUESTIONS. USEFUL SYSTEMS. A thick, asymmetrical instrument fills the right foreground; type and geometry overlap in a deep blue field.
2. **Observe:** approach the opening; the shell separates and the camera follows the gap. “I follow the odd detail.” The visitor learns how curiosity turns into investigation.
3. **Connect:** emerge into an exploded arrangement. Real interests remain readable in HTML while rails and a single authored Trace connect the physical pieces.
4. **Stay:** pieces reorganize into a coherent assembly. “I stay with the hard bit.” The animation expresses iteration without asking the visitor to click a destruction demo.
5. **People:** a second plane enters and changes alignment. “A different view changes the work.” Collaboration changes the object rather than adding more graph nodes.

Native scrolling is the input. Reversing scroll reverses the scene. Direct navigation skips the sequence. Reduced motion, no JavaScript and WebGL failure receive a normal readable document.

## Quality gate

- The first frame has a subject, readable name/headline and purposeful empty space.
- Scrolling changes distance, silhouette and structure, rather than just opacity.
- The same motion value drives DOM and WebGL.
- No click, drag, sound or animation completion gates the story.
- 320 / 390 / 768 / 1024 / 1440px captures, actual intermediate frames and idle-render checks.
- No hardware FPS claim based on headless capture.

The existing components remain in the repository. Removing them from the homepage is a narrative decision, not deleting their working systems.
