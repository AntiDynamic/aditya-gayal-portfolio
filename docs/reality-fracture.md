# Reality fracture

For the subsequent cleanup of exterior labels/audio and the gentler word/white-point timing, see `clean-pull.md`.

The revised direction replaces the printed panels, decorative charts and portfolio/project labels with free-standing words: TIME, SPACE, LIGHT, BEFORE, AFTER, HERE, NOW and REALITY. This is an expressive imagined interior, not a scientific claim about an observer inside a black hole.

Each letter is three independently deformable bands. Words initially share a baseline in perspective space. During the existing .575–.855 interior interval, the letters stretch, then separate across position, depth and orientation. A bounded spatial fault displaces their horizontal bands during the fall; it does not flash or run a random glitch timer. The field contracts into the existing singularity sequence. Distance attenuation and near-camera fading prevent an opaque wall of giant type.

The exterior camera distance is multiplied by a smoothly easing .74–1 factor during the early approach, giving the black hole approximately one-third more apparent size in the opening before converging to the existing close-approach trajectory. The shadow remains stationary when scroll position is fixed. Stronger density contrast, narrow filament brightness and dark lanes make the existing differential accretion flow more visible. There is no new animation-speed ramp or decorative ring layer.

The independent simulation clock, shared direct/lensed material sampling, existing palette, native scroll track, reduced-motion controls, context-loss fallback, white point, whiteout, name reformation and portfolio destination remain. The semantic hidden narrative now describes the revised interior. Lower portfolio components are untouched.

## Rendering

One shared 1024×512 glyph atlas replaces the 2048×2048 sheet atlas, reducing that texture's RGBA allocation from 16 MiB to 2 MiB. The instanced interior remains a single additional draw call. Desktop uses 234 letter bands / 7,488 triangles; mobile uses 177 / 5,664; reduced motion uses 117 / 3,744. The former desktop sheet field used 19,200 triangles. Reduced motion disables the stretch, spatial fault and letter scattering while retaining the existing shorter dissolve/collapse progression.

Filament contrast changes reuse the existing noise and heat calculations. No extra disk noise samples, textures, draw calls or postprocessing were added in this revision. Continuous exterior rendering still has the idle energy cost documented in `black-hole-motion.md`.
