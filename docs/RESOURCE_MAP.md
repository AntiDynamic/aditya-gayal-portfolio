## Primary coding references

- [Lusion's official WebGL Scroll Sync](https://github.com/lusionltd/WebGL-Scroll-Sync): canvas/DOM synchronization trade-offs, bounds caching and visibility. This is an MIT demonstration, **not the full Lusion website source**. Our bounded sticky scene avoids page-wide anchored 3D drift; both typography and camera read the same progress.
- [GSAP ScrollTrigger documentation](https://gsap.com/docs/v3/Plugins/ScrollTrigger/): local progress, refresh and cleanup. No plugin-owned pinning is required; CSS sticky provides the stage.
- [R3F scaling performance](https://r3f.docs.pmnd.rs/advanced/scaling-performance): demand rendering and invalidation for imperative motion. Idle rendering must stop.
- [Curly Tubes from the Lusion Website](https://tympanus.net/codrops/2021/05/17/curly-tubes-from-the-lusion-website-with-three-js/): Yuri Artiukh's independent coding study, **not Lusion's source**. Useful for spatial curves; no code/assets copied.
- [Lusion's My Little Storybook](https://lusion.co/projects/my_little_story_book/): authored geometry and illustration share a world. Principle reference, no assets reused.

No external model, HDRI, texture or audio download is required for this pass. The new GLB is generated locally and its report records size/triangles. Existing licensed assets remain documented separately.
