# Depth and performance pass — 2026-10-09

The black-hole and room compositions are unchanged. The black-hole opening now exposes restrained Room and Website shortcuts. Desktop room inspection restores pointer lock from the same Back/E interaction that closes the object; Escape still releases it. The touch-only room remains an authored, swipeable set of viewpoints with tap-to-inspect controls, **not** free walking. Phone asset preparation is allowed up to 30 seconds before falling back to the accessible website; desktop allows 20 seconds.

The room renderer stops requesting frames when a guided view is settled, waking for view changes, inspection, recovery, and handoff. The portfolio defers below-the-fold image loading and only waits for eager media at first readiness. Work media and selected headings gain restrained perspective and depth; semantic DOM content and native image backing remain intact. Reduced-motion mode disables these depth movements.

The post-room loop is an original 96 BPM, 40-second synthesized composition, rebuilt from `scripts/assets/compose-portfolio-music.mjs` without samples. It remains user-activated because browser audio policies and surprise playback make forced music unreliable. Black-hole text intervals remain silent. Objective FFmpeg analysis measured approximately −21.5 dB mean and −7.2 dB peak on the new MP3; subjective musical fit still needs headphone review.

Local production-build QA passed at 1440, 1024, and 390 pixels: image decoding, music control, security headers, direct links, black-hole shortcuts, and no horizontal overflow. Desktop room QA passed walking/collision, automatic mouse-look restoration, recovery, and monitor handoff. A separate 390-pixel touch run passed swipe navigation, inspection, direct/no-JS/WebGL-failure routes, and handoff without browser or console errors. The mobile room reported 25 draw calls, 15,344 triangles, 49 textures, a 487×1055 drawing buffer, about 1.31 ms average WebGL draw time, and an idle renderer at the captured inspection state. Those are emulated-Chromium measurements, **not physical-phone FPS**. An earlier desktop capture reported 32 draw calls, 25,776 triangles, 51 textures, and about 2.05 ms WebGL draw time. Full-site smooth-scroll/reduced-motion activation checks also passed.

Evidence: `visual-qa/depth-pass-release/`, `visual-qa/depth-pass-room-mobile/`, `visual-qa/depth-pass-fluidity/`, and `visual-qa/depth-pass-room/`. The mobile full-playthrough recording is under `visual-qa/depth-pass-room-mobile/recordings/`. QA output is local and excluded from deployment. Known limits: phone testing is emulated rather than iOS/Android hardware; guided phone views are not free walking; generated music is not a live performance; and this pass does not establish universal 60 FPS or Lusion-level art direction.
